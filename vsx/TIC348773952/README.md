# TIC 348773952 (BD-13 1046)

A detached eclipsing binary with a 5.078-day period, not previously catalogued as variable. Its
period matches the star's Gaia DR3 spectroscopic orbit, and ASAS-SN V data show the primary eclipse
back to 2013. Prepared for VSX as a new EA; the full analysis is in [report.pdf](report.pdf).
