# TIC 434331752 (ATO J093.6734+17.5725)

A spotted variable star with a 1.385-day period. TESS, ASAS-SN and ATLAS each recover the
period independently. It was submitted to VSX as a new variable; the full analysis is in
[report.pdf](report.pdf).

## Discovery

| | |
|---|---|
| Found | 2026-10-10, while vetting a transit candidate on the neighbouring star TIC 434331772 |
| How | TIC 434331772's 12.56-day "transit" was traced in TESS difference images to this star, 30″ away; its own light curve is dominated by a 1.385-day variation |
| Submitted | 2026-10-11 to VSX, type BY; provisional designation ATO J093.6734+17.5725 |

## Star

TIC 434331752 = 2MASS J06144163+1734211 = Gaia DR3 3370333679817531648; RA 93.67348,
Dec +17.57258 (J2000); V 13.58, G 13.35, T 12.81; Teff ≈ 5600–5700 K, log g 4.06,
R ≈ 1.48 R☉ (TIC); parallax 1.67 mas (about 600 pc); Gaia RUWE 1.67.

| Range | V 13.53–13.57 (ASAS-SN, 2014–2018) |
| TESS amplitude | half-amplitude about 1% (2021), about 2.5% (2023) |
| Second period | 2.28 d, in 4 of 5 TESS sectors, from the same position |

## Summary of the evidence

- **Three independent surveys** give the same period, spanning 2014 to 2023: ASAS-SN,
  ATLAS and TESS. TESS observes continuously, which rules out the ground surveys' one-day
  alias at 3.564 d.
- **On this star:** in TESS images the signal is centred on TIC 434331752 in every
  sector, and similar nearby stars don't show it.
- **Previously uncatalogued:** VSX, ASAS-SN, ZTF and Gaia DR3 don't list it as a variable.
  ATLAS has it only as a candidate classed `dubious`.
- **Likely nature:** spots on a young, active star, probably in an unresolved binary. The
  evidence is the second 2.28-day period, Gaia RUWE 1.67, a ROSAT X-ray counterpart and
  possible membership of the young group Theia 399 (about 135 Myr). Spectroscopy would
  test this.
